## 🤖 CONFIGURACIÓN DEL BOT

### Todos los mensajes con "Hola" activan el bot:

1. **"Hola" solo o con "packs disponibles"** → Muestra menú completo
2. **"Hola" + pack específico** → Va directo a ese pack
3. **"Hola" + "hacer un pedido"** → Inicia flujo de pedido
4. **"Hola" + "información"** → Da info específica
5. **"Hola" + "consulta sobre pedido/cuenta"** → Deriva a humano

---

## 📋 KEYWORDS PARA EL BOT

El bot debe reconocer estas palabras clave DESPUÉS de "Hola":

| Keyword | Acción del Bot |
|---------|----------------|
| `packs disponibles`, `conocer los packs` | Mostrar menú completo |
| `hacer un pedido`, `quiero pedir` | Iniciar flujo de pedido |
| `me interesa`, `quiero información` + pack | Info de pack específico |
| `días de entrega` | Calendario de entregas |
| `llegan a mi zona`, `zonas de cobertura` | Info de zonas |
| `información general`, `sobre BiKitchen` | Info general |
| `recomendaciones` | Sugerencias personalizadas |
| `promoción mensual` | Info de promo actual |
| `consulta sobre mi pedido` | Derivar a humano |
| `ayuda con mi cuenta` | Derivar a humano |
